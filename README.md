### 1. 🏛️ [Kintsugi Serves — White-Label Tax Compliance Demo](https://github.com/muhammadatiq1/kintsugi-serves-wl-demo)

> A reference implementation for embedding U.S. sales-tax compliance inside a partner-branded onboarding flow.

A working demonstration of how to wrap a regulated, KYC-style workflow (entity types, EINs, ownership structure, state registrations, bank details) inside a clean, sequential UI — built on top of the official **Kintsugi Tax Platform SDK**.

**Stack:** Meteor.js · Bulma · `@kintsugi-tax/tax-platform-sdk` · jQuery · Lodash · Vercel

🔗 **Live:** [kintsugi-serves-wl-demo.vercel.app](https://kintsugi-serves-wl-demo.vercel.app)

> *Why it matters:* Embedding compliance inside another product is one of fintech's harder UX problems. The API has to stay rigid; the user experience has to feel calm. This is a working draft of that bridge — and a direct companion to my fintech & tax-automation product work.

### 2. 🌿 [GreenScale — Sustainability & Carbon Accounting Platform](https://github.com/muhammadatiq1/GreenScale-Sustainability-Platform)

> A multi-tenant SaaS for tracking, analyzing, and reporting carbon emissions across Scope 1, 2, and 3.

Probably the most ambitious project in this list. Multiple roles (super admin, owner, manager, contributor), a Scope 3 supply-chain module, a financial budgeting layer that ties emissions targets to operational budgets, an embedded AI assistant, CSV/PDF compliance exports, and a hardened owner dashboard with its own security test suite.

**Stack:** React + TypeScript · Tailwind CSS · Recharts · FastAPI (Python) · SQLAlchemy · MySQL

🔗 **Live:** [green-scale-sustainability-platform.vercel.app](https://green-scale-sustainability-platform.vercel.app)

> *Why it matters:* This is what I reach for when I want to demonstrate "real B2B SaaS shape" rather than a prototype — the kind of project where the early architecture decisions decide which features are even possible later.

### 4. 🎓 [Student Success System](https://github.com/muhammadatiq1/Student-Success-System)

> A web-based academic analytics tool that turns student CSV exports into the few observations a teacher can actually act on.

Flask front, pandas-backed core, server-rendered Matplotlib/Seaborn charts, and enough scikit-learn surface area to graduate from descriptive statistics into outcome modeling without re-architecting. Includes sample data and a synthetic dataset generator for realistic load testing.

**Stack:** Flask · pandas · NumPy · scikit-learn · Matplotlib · Seaborn · openpyxl · Gunicorn

🔗 **Live:** [student-success-system-mu.vercel.app](https://student-success-system-mu.vercel.app)

> *Why it matters:* The interesting design question isn't "can pandas compute a mean?" — it's "what's the smallest, clearest output that would actually change a teacher's behavior on a Tuesday morning?"

### 6. 🛠️ [Revoke — Repository Automation Scripts](https://github.com/muhammadatiq1/Revoke)

> A small toolkit of cross-platform Python, Node, and Batch scripts for cleaning up Git state and automating push workflows.
