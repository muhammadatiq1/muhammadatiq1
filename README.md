**🎓 Full-stack web + mobile transport management system built for Hamdard University Islamabad Campus**

</div>

> An end-to-end platform for managing the campus-wide transportation network — covering route administration, bus assignment, driver management, student registration, real-time scheduling, and on-the-go mobile access for students and drivers. Built natively against the realities of how a university transport office actually operates.

#### 🎯 The Problem It Solves

University transport systems are deceptively complex. Hundreds of students need to know which bus picks up where and when. Drivers need clear assignments and accurate route maps. The transport office needs to manage capacity, handle exceptions, track attendance, and audit who actually rode each route. Most universities run this on a mix of paper, spreadsheets, and noticeboards. This system replaces all of that with a single source of truth that students access from their phones and admins control from a clean web dashboard.

#### ✨ Core Capabilities

| 🌐 Web Admin Panel (Laravel) | 📱 Student & Driver Mobile App (React Native) |
|---|---|
| 🚌 Route creation & management | 🔍 Live route search & schedules |
| 👥 Student registration & enrollment | 🎫 Student bus pass / digital ID |
| 🧑‍✈️ Driver assignment & profiles | 📍 Pickup point lookup & timings |
| 🗺️ Stop & pickup-point administration | 🔔 Push notifications for changes |
| 📊 Reporting & attendance dashboards | 👤 Personalized student dashboard |
| 🔐 Role-based access (Admin / Coordinator) | 🚌 Driver portal for daily route view |
| 📅 Schedule & timetable management | 📞 In-app contact with transport office |
| 💳 Fee tracking & payment status | 📱 Cross-platform (iOS + Android) |

This was a real-world enterprise build — not a portfolio prototype.
